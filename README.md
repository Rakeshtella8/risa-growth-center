# RISA Growth Center

Command centre for the CampusFest attendee-growth campaign (RISA Labs Growth APM assignment, Challenge A).
Work in progress. The full README (research, assumptions, calculations, setup, testing, limitations) comes with the app.

- `supabase/sql/` – schema, metric views (single source of truth for dashboard and chatbot), loaders
- `data/` – original 2025 dataset (xlsx) and JSON export used by the loader
- `scripts/` – data export helpers
- `tests/` – metric regression tests
